# HomeSec

HomeSec is an AI-assisted home network security dashboard that monitors devices connected to a local network, evaluates security risks using a deterministic rule engine, and provides AI-generated explanations and remediation recommendations.

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- React Query

### Backend
- FastAPI
- Python

### Database
- PostgreSQL

### AI
- Google Gemini API

## Planned Features

- Network device discovery
- Device inventory
- Rule-based risk scoring
- AI security explanations
- Security dashboard
- Scan history
- Alert management
